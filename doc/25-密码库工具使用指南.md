# 密码库工具使用指南

> 密码库是一款本地化的密码管理工具，基于 Argon2id + AES-256-GCM 加密方案，帮助你安全存储和管理各类账号凭证，所有数据仅存储在本地，无任何网络传输。

## 安全架构

密码库采用多层安全设计，确保你的敏感数据得到最高级别的保护：

| 安全特性 | 说明 |
|----------|------|
| **主密码哈希** | Argon2id 算法派生加密密钥，抗暴力破解 |
| **逐条加密** | 每条密码记录使用 AES-256-GCM 独立加密 |
| **本地存储** | 数据仅存储在本地 SQLite 数据库，无网络传输 |
| **自动锁定** | 30 分钟无操作自动锁定，需重新输入主密码 |
| **剪贴板保护** | 复制密码后 15 秒自动清空剪贴板 |

## 首次使用

### 设置主密码

首次打开密码库时，需要设置主密码。主密码是解锁所有密码记录的唯一凭证。

**使用步骤：**
1. 打开密码库工具，系统提示设置主密码
2. 输入主密码（至少 8 位字符）
3. 再次输入确认主密码
4. 观察密码强度指示条
5. 点击「确认设置」完成初始化

**密码强度指示：**
- 🟥 极弱：长度不足或过于简单
- 🟧 弱：仅包含单一字符类型
- 🟨 一般：包含两种字符类型
- 🟩 强：包含三种字符类型且长度 ≥ 12
- 🟦 极强：包含四种字符类型且长度 ≥ 16

> ⚠️ **重要警告**：主密码遗忘后**无法恢复**！所有加密的密码数据将永久无法访问。请务必牢记主密码，或将其安全地记录在物理介质上。

## 核心功能

### 1. 添加密码记录

**使用步骤：**
1. 点击顶部「➕ 添加」按钮
2. 填写密码记录信息
3. 点击「保存」完成添加

**字段说明：**

| 字段 | 必填 | 说明 |
|------|------|------|
| **标题** | ✅ | 记录名称，如"GitHub 账号" |
| **用户名** | ❌ | 登录用户名或邮箱 |
| **密码** | ✅ | 账号密码，输入时实时检测强度 |
| **URL** | ❌ | 相关网站地址 |
| **分类** | ❌ | 归属分类，便于管理 |
| **标签** | ❌ | 自定义标签，支持多标签 |
| **备注** | ❌ | 额外补充信息 |

### 2. 查看与复制密码

密码默认以掩码形式（●●●●●●●●）显示，确保他人无法窥视。

- **显示/隐藏密码**：点击记录中的 👁️ 眼睛图标切换明文/掩码
- **一键复制**：点击 📋 按钮将密码复制到剪贴板
- **自动清空**：复制后 15 秒自动清空剪贴板内容，防止密码残留

### 3. 编辑密码记录

**使用步骤：**
1. 点击目标记录进入详情
2. 点击「编辑」按钮
3. 修改需要更新的字段
4. 点击「保存」确认修改

### 4. 删除密码记录

**使用步骤：**
1. 点击目标记录进入详情
2. 点击「删除」按钮
3. 在确认弹窗中再次确认删除操作

> ⚠️ 删除操作不可撤销，请谨慎操作。

### 5. 搜索与筛选

快速定位目标密码记录：

- **关键词搜索**：支持按标题、用户名、URL 进行模糊匹配搜索
- **分类筛选**：点击分类标签快速过滤对应分类下的记录
- **实时过滤**：输入关键词后立即显示匹配结果

### 6. 分类管理

通过分类组织密码记录，便于快速定位。

**默认分类：**
- 🌐 网站
- 🖥️ 服务器
- 💻 开发
- 📧 邮箱
- 💰 金融
- 🔑 其他

**自定义分类：**
- 支持创建自定义分类
- 支持修改分类名称
- 支持删除空分类

### 7. 密码强度检测

添加或编辑密码时，工具会实时评估密码强度：

| 评分 | 等级 | 说明 |
|------|------|------|
| 0 | 极弱 | 过短或在常见密码列表中 |
| 1 | 弱 | 仅含单一字符类型 |
| 2 | 一般 | 含两种字符类型 |
| 3 | 强 | 含三种字符类型，长度足够 |
| 4 | 极强 | 含四种字符类型，长度充裕 |

## 安全注意事项

- 🔑 主密码是唯一的密钥，遗忘后所有密码将**无法恢复**
- 💪 建议使用强主密码（12 位以上，混合大小写字母、数字和特殊字符）
- 💾 密码数据仅存储在本地 SQLite 数据库中
- 🔐 所有密码使用 AES-256-GCM 单独加密，互不影响
- ⏰ 30 分钟无操作自动锁定，防止他人访问
- 📋 复制密码后 15 秒自动清空剪贴板
- 💾 建议定期备份数据库文件

## 使用场景

### 场景 1：管理服务器密码

存储多台服务器的 SSH/FTP 登录凭证，按「服务器」分类管理，需要时快速搜索复制。

### 场景 2：在线服务账号

统一管理各类在线服务（GitHub、云平台、邮箱等）的账号密码，告别记不住密码的烦恼。

### 场景 3：API Key 与 Token

安全存储各类 API Key、Access Token、Secret Key，避免明文保存在代码或配置文件中。

### 场景 4：数据库连接凭证

保存开发、测试、生产环境的数据库连接信息，方便团队成员快速获取。

## 快捷键与技巧

- 支持通过全局快捷键快速切换到密码库工具
- 搜索支持模糊匹配，输入部分关键词即可定位
- 合理使用分类和标签，便于密码记录的组织管理
- 定期更新重要账号的密码，提升安全性
- 可配合「密码生成器」工具生成高强度随机密码

## 小结

密码库工具提供了企业级的加密安全保障与简洁直观的操作体验，让你在本地安全管理所有敏感凭证。基于 Argon2id + AES-256-GCM 的加密方案确保即使数据库文件泄露，密码数据也无法被破解。
