# Base32 编解码工具使用指南

> Base32 编码在某些特殊场景下非常有用，比如 TOTP 密钥、Magnet 链接等。本文介绍 WATools 中 Base32 编解码工具的功能和使用方法。

## 界面总览

Base32 编解码工具采用**双栏布局**，左侧输入、右侧输出，顶部有实时状态栏。

## 核心功能

### 1. 编码（文本 → Base32）

将普通文本转换为 Base32 编码。

**使用步骤：**
1. 在左侧输入框粘贴或输入文本
2. 点击「编码」按钮
3. 右侧显示 Base32 编码结果

**示例：**
```
输入: Hello World
输出: JBSWY3DPEBLG64TMMQ======
```

### 2. 解码（Base32 → 文本）

将 Base32 编码还原为原始文本。

**使用步骤：**
1. 在左侧输入框粘贴 Base32 编码
2. 点击「解码」按钮
3. 右侧显示解码后的原始文本

**示例：**
```
输入: JBSWY3DPEBLG64TMMQ======
输出: Hello World
```

### 3. 状态栏

顶部状态栏会实时显示操作状态：

- **空闲状态**：🏷️ 输入文本后进行 Base32 编码或解码
- **成功状态**：✓ 转换完成
- **错误状态**：⚠ 显示具体错误信息（如无效的 Base32 字符）

## 复制功能

输出区域底部有 **📋 复制** 按钮，一键将结果复制到剪贴板。

## 清空操作

点击 **「🗑️ 清空」** 按钮可以同时清除输入框和输出区域的内容。

## 实际使用场景

### 场景 1：TOTP 密钥处理

配置 Google Authenticator 或类似应用时，手动输入 Base32 编码的密钥进行验证。

### 场景 2：Magnet 链接解析

从 Magnet 链接中提取 Base32 编码的哈希值并解码查看原始数据。

### 场景 3：跨系统数据传递

某些系统只支持 Base32 编码（避免大小写混淆），使用此工具进行编解码转换。

## Base32 编码特点

| 特性 | 说明 |
|------|------|
| **字符集** | A-Z（26 个字母）+ 2-7（6 个数字）= 32 个字符 |
| **填充字符** | `=` 用于补齐长度 |
| **大小写** | 不区分大小写（解码时自动处理） |
| **编码效率** | 每 5 字节原始数据编码为 8 字节 Base32 |

## 小结

Base32 编解码工具提供了简洁直观的界面，支持文本与 Base32 编码的双向转换。无论是处理 TOTP 密钥、Magnet 链接还是其他 Base32 编码数据，都能快速完成。
