# Hex 编解码工具使用指南

> Hex（十六进制）编码是开发调试中的常用格式，广泛应用于二进制数据查看、网络协议分析和底层数据表示。本文介绍 WATools 中 Hex 编解码工具的功能和使用方法。

## 界面总览

Hex 编解码工具采用**双栏布局**，左侧输入、右侧输出，顶部有实时状态栏。

## 核心功能

### 1. 编码（文本 → Hex）

将普通文本转换为十六进制字符串表示。每个字节对应两个十六进制字符。

**使用步骤：**
1. 在左侧输入框粘贴或输入文本
2. 点击「编码」按钮
3. 右侧显示 Hex 编码结果

**示例：**
```
输入: Hello World
输出: 48656c6c6f20576f726c64
```

```
输入: WATools
输出: 5741546f6f6c73
```

### 2. 解码（Hex → 文本）

将十六进制字符串还原为原始文本。

**使用步骤：**
1. 在左侧输入框粘贴十六进制字符串
2. 点击「解码」按钮
3. 右侧显示解码后的原始文本

**示例：**
```
输入: 48656c6c6f20576f726c64
输出: Hello World
```

```
输入: e4b8ade69687
输出: 中文
```

### 3. 状态栏

顶部状态栏会实时显示操作状态：

- **空闲状态**：🔣 输入文本后进行 Hex 编码或解码
- **成功状态**：✓ 转换完成 │ 输入: X chars │ 输出: X chars
- **错误状态**：⚠ 显示具体错误信息（如无效的十六进制字符、奇数长度等）

## 复制功能

输出区域底部有 **📋 复制** 按钮，一键将结果复制到剪贴板。

## 清空操作

点击 **「🗑️ 清空」** 按钮可以同时清除输入框和输出区域的内容。

## 实际使用场景

### 场景 1：二进制数据查看

查看文件的二进制内容时，将原始字节序列转换为可读的十六进制表示，方便分析文件格式和数据结构。

### 场景 2：网络协议调试

抓包工具捕获的数据包通常以 Hex 格式展示，使用此工具可以快速将 Hex 数据转换为可读文本，辅助协议分析。

### 场景 3：颜色值转换

Web 开发中颜色值常用 Hex 表示（如 `#FF5733`），可用此工具验证颜色值对应的 RGB 字节。

### 场景 4：加密数据预览

加密算法的输出通常为字节数组，转换为 Hex 字符串便于存储、传输和比对。

## Hex 编码特点

| 特性 | 说明 |
|------|------|
| **字符集** | 0-9、a-f（共 16 个字符） |
| **大小写** | 编码输出小写，解码不区分大小写 |
| **编码效率** | 每 1 字节原始数据编码为 2 个 Hex 字符 |
| **无填充** | 不需要填充字符 |

## 快捷键与技巧

- 输入后直接按 `Enter` 触发编码
- 点击输出区域的内容可快速复制
- 支持带空格或不带空格的 Hex 字符串输入

## 小结

Hex 编解码工具提供了简洁直观的界面，支持文本与十六进制编码的双向转换。无论是调试网络协议、查看二进制数据还是处理加密输出，都能快速完成。
