# 主题切换与个性化配置指南

> 让 WATools 变成你的专属工具箱。本文介绍所有可配置项：主题、字体、工具默认设置等。

## 设置入口

点击左侧侧边栏底部的 **「⚙️ 设置」** 进入设置页面。

### 切换方式

1. 进入设置页面
2. 在主题选择区域点击你想要的主题
3. 界面**即时切换**，无需重启

> 💡 **提示**：主题选择会自动保存到本地存储，下次打开 WATools 自动恢复你上次选择的主题。

## 编辑器设置

### 字体大小

设置工具输入区域的字体大小，可选：

- 小
- 中（默认）
- 大
- 特大

> 建议：如果你经常处理大段 JSON 或代码，选择较大字体更易阅读。

<!-- 📸 截图占位：字体大小选择效果截图 -->
![字体大小](images/screenshot-font-size.png)

## 工具默认设置

### JSON 缩进

设置 JSON 格式化时的默认缩进方式：

- **2 空格**（默认）
- **4 空格**

此设置也可以在 JSON 格式化工具的输出区域临时更改。

### 自动验证

开启或关闭 JSON 输入的自动验证功能：

- **开启**（默认）：输入 JSON 后自动校验语法
- **关闭**：需要手动点击「验证」按钮

> 💡 如果粘贴大型 JSON 时感到卡顿，可以关闭自动验证，改为手动触发。

### 时间格式

设置时间转换工具的默认输入格式：

- 自动检测（默认）
- Unix 秒
- Unix 毫秒
- ISO 8601
- RFC 2822
- 本地时间

## 配置持久化

所有设置项都通过 **Pinia + SQLite** 双层持久化：

1. **Pinia 状态管理**：应用运行时实时生效
2. **SQLite 本地数据库**：关闭应用后配置不丢失

你不需要手动保存，修改即刻生效并持久化。

## 小结

WATools 提供了主题、字体、工具默认值等维度的个性化配置，让你把工具箱调整到最舒适的状态。所有设置自动保存，开箱即用。
