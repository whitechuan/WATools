# 别再往在线工具粘贴敏感数据了！本地工具箱才是正解

> 你有没有把生产环境的 JWT Token 粘贴到 jwt.io 上？你有没有把包含用户信息的 JSON 贴到某个在线格式化工具里？如果有，这篇文章你一定要看完。

## 一个真实场景

某天你在排查线上 Bug，需要解析一个用户反馈的 JWT Token。你习惯性地打开 jwt.io，把 Token 粘贴进去——

等一下。

那个 Token 的 Payload 里包含了用户的 `userId`、`email`，甚至可能有 `role: admin`。你刚刚把这些信息发送到了第三方服务器。

**这不是危言耸听，这是每天都在发生的事情。**

## 在线工具的三大隐患

### 1. 数据泄露风险

大多数在线工具需要把你的数据发送到服务器进行处理。即使它们声称"不会保存数据"，你也无法验证。在网络传输过程中，数据可能经过多个节点。

### 2. 网络依赖

- 公司内网可能禁止访问外部工具网站
- 网络不稳定时工具无法使用
- 网站可能突然下线或更换域名

### 3. 效率问题

- 每次使用都要打开浏览器、搜索、等待加载
- 不同工具分散在不同网站，来回切换
- 广告弹窗影响体验

## 本地工具箱的优势

| 对比项 | 在线工具 | 本地工具箱 |
|--------|---------|-----------|
| 数据安全 | 数据发送到第三方 | 全程本地处理 |
| 网络依赖 | 必须联网 | 离线可用 |
| 启动速度 | 浏览器 + 加载页面 | 秒级启动桌面 App |
| 使用体验 | 风格各异，有广告 | 统一 UI，无干扰 |
| 历史记录 | 通常不保存 | 本地持久化存储 |

## WATools：一个为安全而生的本地工具箱

**WATools** 就是为解决这个问题而生的。它是一个基于 Tauri 2 + Vue 3 的桌面应用，所有数据处理都在本地完成。

### JSON 格式化

不需要把 API 响应贴到网上。本地直接解析和格式化，支持：
- 格式化（Pretty Print）
- 压缩（Minify）
- 语法校验与错误定位

### JWT 解析

Token 不出本机。三段式清晰展示：
- Header：算法和类型信息
- Payload：声明数据（自动识别标准字段）
- Signature：签名信息

### 时间转换

时间戳与各种日期格式互转，支持：
- Unix 时间戳（秒/毫秒）
- ISO 8601
- RFC 2822
- 多时区对照

## 数据流对比

**在线工具的数据流：**
```
你的敏感数据 → 浏览器 → 网络传输 → 第三方服务器 → 处理结果 → 网络传输 → 浏览器
```

**WATools 的数据流：**
```
你的敏感数据 → 本地应用 → Rust 后端处理 → 结果展示
```

没有网络传输，没有第三方服务器。数据从始至终都在你的电脑上。

## 不只是安全，还有效率

WATools 把所有常用工具集中在一个应用中：

- **统一入口**：一个 App 解决所有工具需求
- **快速切换**：侧边栏一键切换工具
- **历史记录**：基于 SQLite 的本地存储，上次的结果随时可查
- **多主题**：6 套新拟态主题，赏心悦目

