# JSON 格式化工具完全指南

> API 调试、配置检查、日志分析——JSON 格式化可能是开发者用得最频繁的工具之一。本文详细介绍 WATools 中 JSON 格式化工具的所有功能和使用技巧。

## 界面总览

JSON 格式化工具采用**双栏布局**，左侧输入、右侧输出，顶部有实时状态栏。

## 核心功能

### 1. 格式化（Pretty Print）

点击 **「格式化」** 按钮，将压缩或混乱的 JSON 转为缩进整齐的可读格式。

**使用步骤：**
1. 在左侧输入框粘贴 JSON
2. 点击「格式化」按钮
3. 右侧显示格式化的结果

<!-- 📸 截图占位：格式化前后对比截图 -->
![格式化前后对比](images/screenshot-json-format-before-after.png)

**缩进设置：** 在输出区域底部可以选择 **2 空格** 或 **4 空格** 缩进，设置会自动保存，下次打开仍生效。

### 2. 压缩（Minify）

将格式化的 JSON 压缩为一行，去除所有空白字符，适用于：
- 减小配置文件体积
- 网络传输前压缩数据
- 对比两个 JSON 的结构差异

### 3. 验证（Validate）

点击 **「验证」** 按钮，检查 JSON 语法是否正确。

**验证成功时**，状态栏显示：
```
✓ 有效 JSON │ 行: 24 │ 键: 8 │ 深度: 3 │ 1024 bytes
```

**验证失败时**，会显示具体的错误信息和修复建议：
```
⚠ 第 3 行第 15 列：意外的字符 │ 💡 可能缺少引号或逗号
```

## 状态栏详解

顶部状态栏会实时展示 JSON 的统计信息：

| 指标 | 说明 | 典型用途 |
|------|------|---------|
| **行** | JSON 总行数 | 了解数据规模 |
| **键** | 所有键的总数 | 评估对象复杂度 |
| **深度** | 最大嵌套层级 | 判断结构是否过深 |
| **bytes** | 原始文本大小 | 传输前评估体积 |

## 语法高亮

输出区域支持 JSON 语法高亮，不同数据类型用不同颜色区分：

- 🔵 **键名（Key）**：蓝色
- 🟢 **字符串值（String）**：绿色
- 🟠 **数字（Number）**：橙色
- 🟣 **布尔值（Boolean）**：紫色

## 复制功能

输出区域底部有一个 **📋 复制** 按钮，一键将格式化后的 JSON 复制到剪贴板。

## 清空操作

点击 **「🗑️ 清空」** 按钮可以同时清除输入框和输出区域的内容，方便开始下一次操作。

## 实际使用场景

### 场景 1：API 响应格式化

从 Postman 或浏览器 DevTools 复制 API 响应后粘贴到 WATools，一键格式化，快速查看数据结构。

### 场景 2：配置文件检查

修改 `package.json`、`tsconfig.json` 等配置文件后，粘贴验证语法是否正确，避免因为一个逗号导致构建失败。

### 场景 3：日志 JSON 分析

服务器日志中的 JSON 通常是压缩格式，粘贴后格式化，配合语法高亮快速定位问题字段。

## 性能表现

得益于 Rust 后端的 `serde_json` 库，WATools 的 JSON 格式化速度极快：

| 数据量 | 格式化耗时 |
|--------|-----------|
| 1 KB | < 1ms |
| 100 KB | < 5ms |
| 1 MB | < 50ms |

大文件也完全不用担心卡顿。

## 小结

JSON 格式化工具虽然功能简单，但在日常开发中使用频率极高。WATools 提供了格式化、压缩、验证、语法高亮、缩进设置等完整功能，满足你的所有 JSON 处理需求。
