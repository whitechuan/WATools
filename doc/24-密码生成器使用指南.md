# 密码生成器使用指南

> 强密码是信息安全的第一道防线。本文介绍 WATools 中密码生成器的功能，包括随机密码生成和密码强度检测（基于 zxcvbn 算法）。

密码生成器采用**双栏布局**，左栏为密码生成配置，右栏为密码强度检测，顶部有实时状态栏。

## 核心功能

### 1. 随机密码生成

根据配置选项生成高质量随机密码。

**使用步骤：**
1. 拖动滑块设置密码长度（8-64 位）
2. 勾选需要包含的字符类型
3. 点击「生成密码」按钮
4. 生成的密码显示在下方，同时自动触发强度检测

**配置选项：**

| 选项 | 字符集 | 默认 |
|------|--------|------|
| 大写字母 | A-Z（26 个） | ✅ 开启 |
| 小写字母 | a-z（26 个） | ✅ 开启 |
| 数字 | 0-9（10 个） | ✅ 开启 |
| 符号 | !@#$%^&*... | ✅ 开启 |

**示例：**
```
配置: 长度=16, 大写+小写+数字+符号
生成: aX9#mK2$pL7@nR4!

配置: 长度=32, 大写+小写+数字
生成: kP7mNx2rTy9wQz4sHj6cVb8nFg3dLa5e

配置: 长度=8, 仅数字
生成: 47291683
```

### 2. 密码强度检测

基于 zxcvbn 算法对密码进行全面的强度评估。

**使用步骤：**
1. 在右栏输入框输入要检测的密码（或生成密码后自动填入）
2. 点击「检测强度」按钮
3. 查看评分、破解时间和改进建议

**评分说明：**

| 评分 | 等级 | 颜色 | 含义 |
|------|------|------|------|
| 0 | 极弱 | 红色 | 极易被猜测或暴力破解 |
| 1 | 弱 | 橙色 | 容易被针对性攻击破解 |
| 2 | 一般 | 黄色 | 能抵御部分在线攻击 |
| 3 | 强 | 浅绿 | 能抵御大部分攻击 |
| 4 | 极强 | 绿色 | 高度安全，破解成本极高 |

**破解时间估算：**

zxcvbn 会估算在不同攻击场景下破解密码所需的时间：

```
示例:
  "password123"  → 破解时间: < 1 秒
  "Tr0ub4dor&3"  → 破解时间: 数小时
  "aX9#mK2$pL7@" → 破解时间: centuries (数百年)
```

**反馈建议：**

算法会给出具体的改进建议，例如：
- 添加一两个不常见的单词
- 避免使用常见密码模式
- 增加密码长度
- 混合使用不同字符类型

### 3. 状态栏

顶部状态栏实时显示操作状态：

- **空闲状态**：⌨️ 配置选项后点击生成
- **成功状态**：✅ 密码已生成
- **错误状态**：显示错误信息（如未选择任何字符类型）

## 实际使用场景

### 场景 1：生成数据库密码

为数据库账户生成高强度随机密码，推荐配置：
```
长度: 32
字符类型: 大写 + 小写 + 数字 + 符号
```

### 场景 2：生成 API Key

为服务间通信生成 API 密钥：
```
长度: 64
字符类型: 大写 + 小写 + 数字（避免符号以兼容 URL）
```

### 场景 3：测试用临时密码

开发测试阶段为测试账户生成临时密码：
```
长度: 12
字符类型: 大写 + 小写 + 数字
```

### 场景 4：评估现有密码安全性

将当前使用的密码输入强度检测，了解是否需要更新为更强的密码。

## 安全建议

> 💡 **密码最佳实践**

- **长度优先**：推荐 16 位以上，长度比复杂度更重要
- **混合字符**：同时包含大小写字母、数字和符号
- **避免模式**：不要使用键盘顺序（qwerty）、重复字符（aaa）、常见替换（p@ssw0rd）
- **唯一性**：每个账户使用不同密码
- **定期更新**：关键账户定期更换密码
- **配合密码管理器**：使用此工具生成的高强度密码，配合密码管理器存储

## 密码强度影响因素

| 因素 | 影响 |
|------|------|
| 长度 | 每增加 1 位，暴力破解时间指数增长 |
| 字符集大小 | 包含更多类型字符扩大搜索空间 |
| 随机性 | 真随机 > 伪模式 > 字典词 |
| 可预测性 | 包含个人信息会大幅降低安全性 |

## 快捷键与技巧

- 生成密码后自动触发强度检测，无需手动点击
- 点击「📋 复制」按钮快速复制生成的密码
- 滑块支持拖动和点击精确设置长度
- 至少选择一种字符类型才能生成密码

## 小结

密码生成器提供了随机密码生成和强度检测两大功能。左栏配置生成选项，右栏实时检测密码强度，帮助开发者快速生成符合安全要求的高强度密码，并对现有密码进行安全评估。
