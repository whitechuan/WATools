# RSA 加密工具使用指南

> RSA 是最经典的非对称加密算法，广泛应用于数字签名、密钥交换和加密通信。本文介绍 WATools 中 RSA 加密工具的三大功能：密钥生成、加密/解密、签名/验证。

## 核心功能

### Tab 1：密钥生成

生成 RSA 密钥对，支持 2048-bit 和 4096-bit 两种长度，输出 PEM 格式。

**使用步骤：**
1. 选择密钥长度（2048 bit 或 4096 bit）
2. 点击「🔑 生成密钥对」按钮
3. 等待生成完成（4096-bit 需要较长时间）
4. 界面显示公钥和私钥的 PEM 格式内容
5. 使用各自的复制按钮保存密钥

**示例输出：**
```
公钥:
-----BEGIN PUBLIC KEY-----
MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...
-----END PUBLIC KEY-----

私钥:
-----BEGIN PRIVATE KEY-----
MIIEvgIBADANBgkqhkiG9w0BAQEFAASCBKgwggSkAgEA...
-----END PRIVATE KEY-----
```

### Tab 2：加密 / 解密

使用 RSA 公钥加密明文，使用私钥解密密文。采用**双栏布局**。

**加密步骤：**
1. 在左栏粘贴 RSA 公钥（PEM 格式）
2. 输入要加密的明文
3. 点击「🔒 加密」按钮
4. 获得 Base64 编码的密文

**解密步骤：**
1. 在右栏粘贴 RSA 私钥（PEM 格式）
2. 输入 Base64 编码的密文
3. 点击「🔓 解密」按钮
4. 获得解密后的明文

**示例：**
```
公钥加密:
  明文: Hello RSA!
  密文: YWJjZGVm...（Base64 编码，每次结果不同）

私钥解密:
  密文: YWJjZGVm...
  明文: Hello RSA!
```

### Tab 3：签名 / 验证

使用 RSA 私钥对消息进行数字签名，使用公钥验证签名的真实性。采用**双栏布局**。

**签名步骤：**
1. 在左栏输入要签名的消息
2. 粘贴 RSA 私钥（PEM 格式）
3. 点击「✍️ 签名」按钮
4. 获得 Base64 编码的数字签名

**验证步骤：**
1. 在右栏输入原始消息
2. 输入 Base64 编码的签名
3. 粘贴 RSA 公钥（PEM 格式）
4. 点击「✅ 验证」按钮
5. 状态栏显示验证结果（✓ 验证通过 / ✗ 验证失败）

**示例：**
```
签名:
  消息: 这是需要签名的重要数据
  签名结果: base64EncodedSignature...

验证:
  消息: 这是需要签名的重要数据
  签名: base64EncodedSignature...
  结果: ✓ 签名验证通过
```

### 状态栏

顶部状态栏实时显示操作状态：

- **空闲状态**：🔐 RSA非对称加密工具 — 仅供开发测试使用，请勿用于生产环境密钥管理
- **成功状态**：✓ 操作完成
- **验证通过**：✓ 签名验证通过（绿色）
- **验证失败**：✗ 签名验证失败（红色）
- **错误状态**：⚠ 显示具体错误信息

## PEM 格式说明

PEM（Privacy Enhanced Mail）是一种常见的密钥编码格式：

```
-----BEGIN PUBLIC KEY-----
Base64 编码的密钥数据（每行 64 个字符）
-----END PUBLIC KEY-----
```

| 类型 | 头部标记 | 用途 |
|------|----------|------|
| 公钥 | `BEGIN PUBLIC KEY` | 加密、验签 |
| 私钥 | `BEGIN PRIVATE KEY` | 解密、签名 |

## PKCS#1 v1.5 填充说明

本工具使用 **PKCS#1 v1.5** 填充方案：

- 加密时在明文前添加随机填充，因此相同明文每次加密结果不同
- 填充会占用部分空间，因此 RSA 可加密的明文长度有限制：
  - **2048-bit 密钥**：最大明文长度 = 245 字节
  - **4096-bit 密钥**：最大明文长度 = 501 字节

> 超过长度限制时工具会提示错误。对于较长数据，建议使用 RSA + 对称加密的混合方案。

## 实际使用场景

### 场景 1：JWT 签名测试

使用生成的 RSA 密钥对测试 RS256 算法的 JWT 签名与验证流程。

### 场景 2：API 认证调试

模拟需要 RSA 签名的 API 请求，验证签名算法实现是否正确。

### 场景 3：加密通信原型

快速搭建非对称加密通信的原型，测试公钥加密、私钥解密的完整流程。

### 场景 4：证书相关调试

在处理 SSL/TLS 证书时，验证公私钥是否匹配。

## 安全注意事项

> ⚠️ **重要提醒**

- 本工具生成的密钥**仅供开发测试使用**，请勿用于生产环境
- 生产环境应使用专业的 PKI 基础设施生成和管理密钥
- 私钥应严格保密，公钥可以公开分发
- 2048-bit 密钥是当前最低安全要求，高安全场景建议使用 4096-bit
- RSA 明文长度有限制，大数据应使用混合加密方案（RSA + AES）
- 密钥生成涉及大素数计算，4096-bit 可能需要数秒

## 快捷键与技巧

- Tab 切换可以保持之前输入的数据不丢失
- 在密钥生成 Tab 生成的密钥可以直接用于其他两个 Tab
- 验证结果会通过状态栏颜色直观展示（绿色通过/红色失败）
- 每个 PEM 输出区域都有独立的复制按钮

## 小结

RSA 加密工具提供了完整的非对称加密功能集：密钥生成、公钥加密/私钥解密、私钥签名/公钥验证。Tab 切换的设计让三大功能互不干扰，适合开发测试中快速验证 RSA 相关功能。
