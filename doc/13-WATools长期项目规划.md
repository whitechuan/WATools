# WATools 长期项目规划

> 将 WATools 打造成 **开发者桌面上不可或缺的瑞士军刀**——一个功能丰富、体验一致、安全可靠的本地开发者工具箱。

## 一、项目愿景

覆盖日常开发中 80% 的轻量工具需求，成为 **Tauri + Vue 桌面应用生态中的标杆开源项目**。核心始终不变：**本地、安全、高效、高颜值**。

## 二、发展阶段

### 第一阶段：夯实基础（0-3 个月）

**核心目标**：打磨现有工具，稳定基础体验，建立用户口碑。

#### 功能完善

- [x] 完成 12 个核心工具开发（时间转换、JSON 格式化、JWT 解析、Hash、URL 编解码、文本 Diff、UUID、颜色转换、正则测试器、Base64、Cron、HTTP 请求器）
- [ ] 修复现有工具边界情况（超大 JSON、特殊 JWT、异常时间戳）
- [ ] 为每个工具补充「历史记录」功能，自动保存最近 50 条
- [ ] 添加「收藏夹」功能，允许用户置顶常用工具
- [ ] 完善搜索功能，支持全局搜索工具名称和描述
- [ ] 优化移动端/小窗口自适应布局

#### 体验优化

- [x] 所有工具支持一键复制、一键清空
- [ ] 所有工具支持撤销/重做

- [ ] 为常用操作添加快捷键（如 Ctrl+Enter 执行、Ctrl+Shift+C 复制）
- [ ] 启动时恢复上次离开的页面和输入内容

#### 文档与社区

- [x] 创建 12 篇 doc/ 系列博客（6 篇引流 + 6 篇使用指南）
- [ ] 补全 `doc/images/` 中的截图（20+ 张）
- [x] 重新设计中英双语 README（AtomCode 风格）
- [x] 创建 .gitignore，正确保留 Cargo.lock
- [x] 明确项目许可证为 Apache License 2.0
- [ ] 录制一个 2 分钟功能介绍视频
- [ ] 在掘金/CSDN/知乎发布 6 篇引流文章
- [ ] 建立 Issue 模板和 PR 模板
- [ ] 发布第一个稳定版 `v1.0.0`

## 三、技术演进路线

## 五、风险与应对

| 风险 | 应对策略 |
|------|---------|
| 功能膨胀导致维护困难 | 坚持模块化设计，每个工具独立维护 |
| 贡献者不足 | 降低贡献门槛，完善文档和模板 |
| 跨平台兼容性问题 | 优先保证 Windows 体验，逐步适配其他平台 |
| 安全问题（敏感数据处理） | 所有计算本地完成，定期安全审计 |
| 与大厂工具竞争 | 专注本地、安全、可定制三大差异化优势 |
