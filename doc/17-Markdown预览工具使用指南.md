# Markdown 预览工具使用指南

> Markdown 是开发者最常用的文档格式，实时预览能大幅提升编写效率。本文介绍 WATools 中 Markdown 预览工具的功能和使用方法。

## 界面总览

Markdown 预览工具采用**双栏布局**，左侧编辑、右侧实时预览，顶部有状态栏。

## 核心功能

### 1. 实时预览

在左侧编辑 Markdown 文本，点击「🔄 刷新预览」按钮，右侧立即渲染 HTML 效果。

**使用步骤：**
1. 在左侧编辑区输入 Markdown 文本
2. 点击「🔄 刷新预览」按钮
3. 右侧显示渲染后的 HTML 效果

### 2. 导出 HTML

点击预览区右上角的 **「📋 导出 HTML」** 按钮，一键复制渲染后的 HTML 源码。

**使用场景：**
- 将 Markdown 转换为 HTML 用于网页
- 生成邮件模板内容
- 导出为静态页面片段

### 3. 状态栏

顶部状态栏会实时显示操作状态：

- **空闲状态**：📖 输入 Markdown 文本进行预览
- **成功状态**：显示渲染结果信息（如字符数、渲染时间）
- **错误状态**：⚠ 显示语法错误提示

## 支持的 Markdown 语法

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

### 文本样式

```markdown
**粗体文本**
*斜体文本*
~~删除线~~
`行内代码`
```

### 列表

```markdown
- 无序列表项 1
- 无序列表项 2
  - 嵌套项

1. 有序列表项 1
2. 有序列表项 2
```

### 链接与图片

```markdown
[链接文本](https://example.com)
![图片描述](image.png)
```

### 代码块

````markdown
```javascript
function hello() {
  console.log("Hello, World!");
}
```
````

### 引用

```markdown
> 这是一段引用文本
> 可以多行书写
```

### 表格

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| A   | B   | C   |
| D   | E   | F   |
```

### 分隔线

```markdown
---
```

## 实际使用场景

### 场景 1：编写技术文档

在 WATools 中编写 README、API 文档等，实时预览效果，确认无误后导出 HTML。

### 场景 2：博客文章草稿

快速撰写博客文章草稿，预览排版效果，满意后复制到博客平台发布。

### 场景 3：邮件内容排版

使用 Markdown 编写邮件内容，导出 HTML 后粘贴到邮件客户端，保持格式美观。

### 场景 4：学习笔记整理

课堂或会议笔记使用 Markdown 记录，实时预览帮助梳理结构。

## 预览样式

Markdown 预览工具采用与 WATools 一致的新拟态风格，渲染效果包括：

- **标题**：带下划线的一级标题，层级分明的二三级标题
- **代码块**：深色背景 + 等宽字体，支持横向滚动
- **引用块**：左侧彩色边框，缩进显示
- **表格**：带边框的表格，表头加粗
- **链接**：主题色显示，带下划线

## 清空操作

点击 **「🗑️ 清空」** 按钮可以同时清除编辑区和预览区的内容。

## 小结

Markdown 预览工具提供了简洁高效的 Markdown 编辑和实时预览功能。无论是编写技术文档、博客文章还是学习笔记，都能帮助你快速完成，并支持一键导出 HTML。
