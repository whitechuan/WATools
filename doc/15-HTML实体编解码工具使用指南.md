# HTML 实体编解码工具使用指南

> 在网页开发、数据处理、安全测试中，HTML 实体编解码是常见需求。本文介绍 WATools 中 HTML 实体编解码工具的功能和使用方法。

## 界面总览

HTML 实体编解码工具采用**双栏布局**，左侧输入、右侧输出，顶部有实时状态栏。

```
┌──────────────────────────────────────────────┐
│  🏷️ 输入文本后进行 HTML 实体编码或解码        │  ← 状态栏
├──────────────────────┬───────────────────────┤
│      输入             │      输出             │
│  ┌────────────────┐  │  ┌────────────────┐   │

└──────────────────────┴───────────────────────┘
```

## 核心功能

### 1. 编码（文本 → HTML 实体）

将特殊字符转换为 HTML 实体，防止 XSS 攻击或在 HTML 中安全显示特殊符号。

**使用步骤：**
1. 在左侧输入框粘贴或输入文本
2. 点击「编码」按钮
3. 右侧显示 HTML 实体编码结果

**示例：**
```
输入: <script>alert('XSS')</script>
输出: &lt;script&gt;alert(&#39;XSS&#39;)&lt;/script&gt;
```

**转换规则：**
| 原字符 | HTML 实体 |
|--------|-----------|
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |
| `"` | `&quot;` |
| `'` | `&#39;` |

### 2. 解码（HTML 实体 → 文本）

将 HTML 实体还原为原始字符。

**使用步骤：**
1. 在左侧输入框粘贴 HTML 实体编码
2. 点击「解码」按钮
3. 右侧显示解码后的原始文本

**示例：**
```
输入: &lt;p&gt;Hello &amp; Welcome&lt;/p&gt;
输出: <p>Hello & Welcome</p>
```

### 3. 状态栏

顶部状态栏会实时显示操作状态：

- **空闲状态**：🏷️ 输入文本后进行 HTML 实体编码或解码
- **成功状态**：✓ 转换完成
- **错误状态**：⚠ 显示具体错误信息

## 复制功能

输出区域底部有 **📋 复制** 按钮，一键将结果复制到剪贴板。

## 清空操作

点击 **「🗑️ 清空」** 按钮可以同时清除输入框和输出区域的内容。

## 实际使用场景

### 场景 1：防止 XSS 攻击

将用户输入的内容进行 HTML 实体编码后再存储或显示，防止恶意脚本执行。

```
用户输入: <img src=x onerror=alert(1)>
编码后: &lt;img src=x onerror=alert(1)&gt;
```

### 场景 2：网页内容提取

从 HTML 源码中提取纯文本内容，将实体解码为可读字符。

```
HTML: &copy; 2024 WATools. All rights reserved.
解码后: © 2024 WATools. All rights reserved.
```

### 场景 3：邮件模板开发

在邮件 HTML 模板中安全地插入动态内容，避免破坏模板结构。

### 场景 4：数据序列化

将包含特殊字符的 JSON 数据嵌入 HTML 页面时，先进行实体编码。

## 常见 HTML 实体

### 常用符号

| 字符 | 命名实体 | 数字实体 | 说明 |
|------|----------|----------|------|
| `<` | `&lt;` | `&#60;` | 小于号 |
| `>` | `&gt;` | `&#62;` | 大于号 |
| `&` | `&amp;` | `&#38;` | 和号 |
| `"` | `&quot;` | `&#34;` | 双引号 |
| `'` | `&apos;` | `&#39;` | 单引号 |
| `©` | `&copy;` | `&#169;` | 版权符号 |
| `®` | `&reg;` | `&#174;` | 注册商标 |
| `€` | `&euro;` | `&#8364;` | 欧元符号 |

### 中文常用实体

| 字符 | 数字实体 | 说明 |
|------|----------|------|
| `中` | `&#20013;` | 中 |
| `文` | `&#25991;` | 文 |
