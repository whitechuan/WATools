# ASCII 转换工具使用指南

> ASCII 码是计算机的基础编码标准，在调试、协议分析、数据转换中经常需要查看和转换 ASCII 码。本文介绍 WATools 中 ASCII 转换工具的功能和使用方法。

## 界面总览

ASCII 转换工具采用**双栏布局**，左侧输入、右侧输出，顶部有实时状态栏。

## 核心功能

### 1. 文本 → ASCII（文本转 ASCII 码）

将文本转换为十进制 ASCII 码，同时显示十六进制对照。

**使用步骤：**
1. 在左侧输入框输入文本
2. 点击「文本 → ASCII」按钮
3. 右侧显示 ASCII 码（空格分隔的十进制数字）
4. 下方显示十六进制对照

**示例：**
```
输入: Hello
输出: 72 101 108 108 111
Hex: 48 65 6C 6C 6F
```

### 2. ASCII → 文本（ASCII 码转文本）

将 ASCII 码还原为原始文本。

**使用步骤：**
1. 在左侧输入框输入 ASCII 码（空格分隔的十进制数字）
2. 点击「ASCII → 文本」按钮
3. 右侧显示转换后的文本

**示例：**
```
输入: 72 101 108 108 111
输出: Hello
```

### 3. 状态栏

顶部状态栏会实时显示操作状态：

- **空闲状态**：🔢 输入文本或 ASCII 码进行转换
- **成功状态**：显示转换结果信息
- **错误状态**：⚠ 显示具体错误信息（如无效的 ASCII 码值）

## 十六进制对照

当执行「文本 → ASCII」转换时，输出区域下方会额外显示 **Hex 对照**，方便查看十六进制表示。

```
十进制: 72 101 108 108 111
十六进制: 48 65 6C 6C 6F
```

## 复制功能

输出区域底部有 **📋 复制** 按钮，一键将 ASCII 码或文本结果复制到剪贴板。

## 清空操作

点击 **「🗑️ 清空」** 按钮可以同时清除输入框和输出区域的内容。

## 实际使用场景

### 场景 1：网络协议调试

分析 TCP/UDP 数据包时，查看载荷的 ASCII 码表示，快速识别协议内容。

```
数据包载荷: GET / HTTP/1.1
ASCII: 71 69 84 32 47 32 72 84 84 80 47 49 46 46 49 46 49
```

### 场景 2：字符编码排查

排查乱码问题时，将文本转换为 ASCII 码，检查是否有非 ASCII 字符（值 > 127）。

### 场景 3：嵌入式开发

在单片机或嵌入式系统开发中，需要将字符转换为 ASCII 码进行通信。

### 场景 4：教学演示

向学生展示字符与 ASCII 码的对应关系，理解计算机编码原理。

## ASCII 码速查表

### 控制字符（0-31）

| 十进制 | 十六进制 | 说明 |
|--------|----------|------|
| 0 | 00 | NUL 空字符 |
| 9 | 09 | TAB 制表符 |
| 10 | 0A | LF 换行 |
| 13 | 0D | CR 回车 |
| 27 | 1B | ESC 转义 |
| 32 | 20 | SPACE 空格 |

### 常用可打印字符（32-126）

| 十进制 | 十六进制 | 字符 | 说明 |
|--------|----------|------|------|
| 48-57 | 30-39 | 0-9 | 数字 |
| 65-90 | 41-5A | A-Z | 大写字母 |
| 97-122 | 61-7A | a-z | 小写字母 |
| 33-47 | 21-2F | ! " # $ % & ' ( ) * + , - . / | 符号 |
| 58-64 | 3A-40 | : ; < = > ? @ | 符号 |
| 91-96 | 5B-60 | [ \ ] ^ _ ` | 符号 |
| 123-126 | 7B-7E | { \| } ~ | 符号 |
