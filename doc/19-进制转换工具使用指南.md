> 二进制、八进制、十进制、十六进制之间的转换是编程和网络调试中的基础需求。本文介绍 WATools 中进制转换工具的功能和使用方法。

## 核心功能

### 1. 进制转换

输入一个数字并选择其进制，工具会自动计算并显示其他三种进制的结果。

**使用步骤：**
1. 在输入框中输入数字
2. 选择输入数字的进制（二进制/八进制/十进制/十六进制）
3. 点击「转换」按钮（或输入时自动触发）
4. 下方四个卡片分别显示二进制、八进制、十进制、十六进制结果

**示例：**
```
输入: 107（十进制）
输出:
  二进制:  1101011
  八进制:  153
  十进制:  107
  十六进制: 6B
```

### 2. 支持的进制

| 进制 | 字符范围 | 前缀 | 典型用途 |
|------|----------|------|----------|
| **二进制** | 0-1 | `0b` | 位运算、硬件调试 |
| **八进制** | 0-7 | `0o` | Unix 文件权限 |
| **十进制** | 0-9 | 无 | 日常计算 |
| **十六进制** | 0-9, A-F | `0x` | 颜色值、内存地址 |

### 3. 状态栏

顶部状态栏会实时显示操作状态：

- **空闲状态**：🧮 输入数字并选择进制进行转换
- **成功状态**：✓ 转换完成
- **错误状态**：⚠ 显示具体错误信息（如无效的进制字符）

## 复制功能

每个结果卡片底部都有 **📋 复制** 按钮，可以单独复制对应进制的结果。

## 清空操作

点击 **「🗑️ 清空」** 按钮可以同时清除输入框和所有结果。

## 实际使用场景

### 场景 1：位运算调试

在编写底层代码时，快速查看数字的二进制表示，辅助位运算调试。

```
十进制 42 → 二进制 101010
检查第 3 位是否为 1：101010 & 001000 = 001000 ✓
```

### 场景 2：颜色值转换

Web 开发中将十进制 RGB 值转换为十六进制颜色码。

```
RGB(255, 128, 0)
255 → FF
128 → 80
0   → 00
颜色码: #FF8000
```

### 场景 3：网络子网计算

计算 IP 地址子网掩码时，需要在二进制和十进制之间转换。

```
子网掩码: 255.255.255.0
二进制: 11111111.11111111.11111111.00000000
CIDR: /24
```

### 场景 4：Unix 权限设置

将八进制权限码转换为可读格式。

```
755 → rwxr-xr-x
644 → rw-r--r--
```

### 场景 5：内存地址分析

在嵌入式开发中，将十六进制内存地址转换为十进制查看实际位置。

```
0x7FFF5FBFF8C0 → 140734799804608
```

## 输入格式支持

工具支持带前缀和不带前缀两种输入方式：

```
十六进制输入:
  0xFF    ← 带前缀
  FF      ← 不带前缀
  ff      ← 小写也可以

二进制输入:
  0b1010  ← 带前缀
  1010    ← 不带前缀
```

## 小结

进制转换工具提供了二/八/十/十六进制之间的快速转换功能，四卡片同时展示所有进制结果，每个结果可单独复制。无论是位运算调试、颜色值转换还是网络计算，都能一键完成。
