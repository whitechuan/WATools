# WATools 高效使用技巧合集

> 用了这么久 WATools，你可能还错过了一些隐藏技巧。本文汇总了所有提效秘籍，让你的工具箱发挥最大价值。

## 通用技巧

### 技巧 1：侧边栏快速切换

WATools 的工具列表在左侧侧边栏，点击即可在不同工具之间切换。每次切换工具时，上一个工具的**输入和输出状态会保留**，方便你在工具之间来回对比。

![侧边栏](images/screenshot-sidebar.png)

### 技巧 2：F12 打开开发者工具

开发模式下按 `F12` 可以打开内置的浏览器开发者工具，用于：
- 查看网络请求
- 调试前端代码
- 检查 DOM 结构
- 查看控制台日志

### 技巧 3：主题即心情

切换主题不需要进入设置页面，在顶部导航栏就可以快速切换。工作累了？换一个主题换个心情。

## JSON 格式化技巧

### 技巧 4：状态栏看统计

JSON 粘贴后不用点「验证」，状态栏会自动显示 JSON 的统计信息（行数、键数、深度、字节数），帮你快速评估数据规模。

### 技巧 5：缩进偏好记忆

在 JSON 输出区切换缩进后（2空格/4空格），下次打开 WATools 会自动恢复你的选择。不用每次重新设置。

### 技巧 6：语法高亮辨识类型

输出区域的 JSON 语法高亮颜色规则：

| 颜色 | 类型 | 说明 |
|------|------|------|
| 🔵 蓝色 | Key | 对象的键名 |
| 🟢 绿色 | String | 字符串值 |
| 🟠 橙色 | Number | 数字 |
| 🟣 紫色 | Boolean | true / false |

快速扫一眼颜色就能知道 JSON 的数据结构。

## 时间转换技巧

### 技巧 7：实时时钟常伴左右

时间转换页面顶部始终显示当前实时时间和 Unix 时间戳，不需要转换就能随时查看。

### 技巧 8：一键填入当前时间

输入框内的 **「当前时间」** 按钮会根据你选择的格式自动填入对应格式的时间值，不需要手动转换格式再粘贴。

### 技巧 9：日历选择器

点击输入框右侧的日历图标，弹出可视化日期选择器，适合需要选择特定日期的场景。选择后会根据当前格式自动转换。

### 技巧 10：点击卡片复制

结果区的 7 个卡片都是可点击的！点击任意一个卡片，对应的值就会自动复制到剪贴板，卡片上会出现 `✓` 标记。

### 技巧 11：复制全部

当你需要把所有格式的时间值都记录下来时，点击结果区右上角的 **「复制全部」** 按钮，一次性复制 7 种格式。

## JWT 解析技巧

### 技巧 12：自动检测过期

解析 JWT 后，状态栏会自动检测 `exp` 字段，告诉你 Token 是否已过期以及过期时间。排查 Token 问题时一眼就能看到关键信息。

### 技巧 13：时间戳自动翻译

Payload 中的 `exp`、`iat`、`nbf` 等时间戳字段会自动转换为可读的日期格式，不需要再去时间转换工具手动查。

### 技巧 14：Tab 切换对比

Header、Payload、Signature 三个 Tab 可以快速切换对比，排查 Token 结构问题。

## Hash 计算技巧

### 技巧 15：一次计算四种算法

Hash 计算器会同时输出 **MD5、SHA-1、SHA-256、SHA-512** 四种结果，不需要分别操作。每个结果卡片下方都有独立的复制按钮。

## 性能技巧

### 技巧 16：大文件不卡顿

得益于 Rust 后端的强大性能，WATools 处理大文件表现出色：

| 工具 | 1MB 数据 | 10MB 数据 |
|------|---------|----------|
| JSON 格式化 | < 50ms | < 500ms |
| Hash 计算 | < 10ms | < 100ms |

> 💡 如果你处理的是超大文件（100MB+），建议关闭 JSON 自动验证以获得更流畅的输入体验。

## 安全技巧

### 技巧 17：数据不出本机

**所有工具的计算都在本地完成**，你的数据不会经过任何网络传输。这一点在使用 JWT 解析和 JSON 格式化时尤为重要——生产环境的 Token 和敏感 JSON 不应该出现在任何第三方网站上。

### 技巧 18：SQLite 历史存储

WATools 使用本地 SQLite 数据库存储历史记录，数据文件位于应用目录下的 `watools.db`。你可以随时删除这个文件来清除所有历史。

## 自定义扩展

### 技巧 19：添加自己的工具

WATools 采用标准化的工具架构，添加新工具只需 4 步：

1. `src-tauri/src/commands/` 下创建 Rust 命令文件
2. `lib.rs` 中注册命令
3. `src/composables/` 下创建前端调用封装
4. `src/views/tools/` 下创建 Vue 页面

然后在路由中注册即可。详细教程参考 [Rust + 前端混合开发入门](./06-Rust+前端混合开发入门-Tauri2桥接实战.md)。

### 技巧 20：自定义主题

你可以创建自己的主题！在 `src/styles/themes/` 目录下新建 CSS 文件，定义对应的 CSS 变量即可。参考现有主题文件的格式：

```css
:root {
  --neu-bg: #your-bg-color;
  --neu-shadow-dark: rgba(...);
  --neu-shadow-light: rgba(...);
  --neu-text: #your-text-color;
  /* ... */
}
```
