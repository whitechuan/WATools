# 每个开发者都该有一个本地工具箱，我造了一个

> 你还在浏览器里收藏一堆在线 JSON 格式化、JWT 解析、时间戳转换网站吗？是时候换个思路了。

## 痛点：碎片化的开发工具

作为开发者，你一定经历过这样的场景：

- 调试 API 时，需要打开一个在线 JSON 格式化网站
- 排查登录问题时，需要找个 JWT 解码工具
- 处理时间戳时，又得搜一个时间转换页面

这些工具有几个共同的问题：

1. **依赖网络**：没网就用不了，公司内网更是噩梦
2. **隐私风险**：把生产环境的 JWT 或敏感 JSON 粘贴到第三方网站？想想就后背发凉
3. **体验割裂**：每个网站 UI 不同，广告满天飞，体验参差不齐

## 解决思路：一个桌面 App 搞定一切

于是我做了 **WATools** —— 一个用 Tauri 2 + Vue 3 构建的本地开发者工具箱。

### 核心优势

| 特性 | 说明 |
|------|------|
| 🔒 数据安全 | 所有计算在本地完成，数据不出你的电脑 |
| ⚡ 启动即用 | 不到 10MB 的安装包，秒级启动 |
| 🎨 统一体验 | 新拟态 UI 风格，所有工具视觉一致 |
| 🌈 多主题 | 6 套精心设计的主题，总有一款适合你 |
| 💾 历史记录 | 基于 SQLite 本地存储，随查随用 |

### 开箱即用的工具集

- **JSON 格式化**：格式化、压缩、校验一步到位
- **JWT 解析**：Header、Payload、Signature 三段式展示，一目了然
- **时间转换**：时间戳与日期互转，多格式多时区全覆盖

## 技术亮点

WATools 采用了当下最热门的技术栈：

- **前端**：Vue 3 + TypeScript + Vite + Pinia
- **后端**：Tauri 2（Rust）
- **存储**：SQLite（通过 tauri-plugin-sql）

这套组合的优势在于：前端用你熟悉的 Vue 生态写界面，后端用 Rust 保证性能和安全性，最终打包成原生桌面应用，体积远小于 Electron 方案。

## 新拟态 UI：不只是能用，还要好看

WATools 自研了一套 `neu` 组件库，包含 Button、Card、Input、Select、Tabs 等基础组件，全部采用新拟态（Neumorphism）设计风格——柔和的阴影和光影效果，让工具不再冰冷。

配合 6 套主题（樱花、薰衣草、薄荷、海风、星空、日落），你可以根据心情随时切换。

## 快速上手

```bash
git clone https://gitcode.com/white_chuan/WATools.git
cd WATools
pnpm install
pnpm tauri dev
```

就这么简单，本地跑起来，告别在线工具。
