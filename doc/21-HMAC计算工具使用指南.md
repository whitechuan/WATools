# HMAC 计算工具使用指南

> HMAC（Hash-based Message Authentication Code）是一种基于密钥的哈希消息认证码，用于验证数据完整性和身份认证。本文介绍 WATools 中 HMAC 计算工具的功能和使用方法。

## HMAC 原理简介

HMAC 是将哈希函数与密钥结合使用的认证机制：

```
HMAC(K, M) = H((K' ⊕ opad) || H((K' ⊕ ipad) || M))
```

- **K**：密钥（Key）
- **M**：消息（Message）
- **H**：哈希函数（如 SHA-256、SHA-512）
- **opad / ipad**：外部/内部填充常量

HMAC 的安全性取决于底层哈希函数的强度和密钥的保密性。

## 核心功能

### 1. HMAC-SHA256 计算

使用 SHA-256 作为底层哈希函数，输出 64 个十六进制字符（256 bit）。

**使用步骤：**
1. 在上方文本框输入要计算 HMAC 的数据
2. 在下方输入框输入密钥（Key）
3. 点击「计算」按钮
4. 右侧 HMAC-SHA256 卡片显示计算结果

**示例：**
```
数据: hello
密钥: secret
HMAC-SHA256: 88aab3ede8d3adf94d26ab90d3bafd4a2083070c3bcce9c014ee04a443847c0b
```

### 2. HMAC-SHA512 计算

使用 SHA-512 作为底层哈希函数，输出 128 个十六进制字符（512 bit）。

**使用步骤：**
1. 在上方文本框输入要计算 HMAC 的数据
2. 在下方输入框输入密钥（Key）
3. 点击「计算」按钮
4. 右侧 HMAC-SHA512 卡片显示计算结果

**示例：**
```
数据: hello
密钥: secret
HMAC-SHA512: b0344c61d8db38535ca8afceaf0bf12b881dc200c9833da726e9376c2e32cff547a63...
```

### 3. 状态栏

顶部状态栏实时显示操作状态：

- **空闲状态**：💡 输入数据和密钥后点击计算
- **成功状态**：✅ HMAC 计算完成
- **错误状态**：❌ 显示具体错误信息

### 4. 复制功能

每个结果卡片的标题栏右侧都有 **📋 复制** 按钮，也可以直接点击结果文本进行复制。

## 实际使用场景

### 场景 1：API 签名验证

许多 API（如 AWS、支付宝、微信支付）使用 HMAC 进行请求签名。用此工具验算本地签名是否与服务端一致。

```
场景示例：
- 将请求参数拼接为字符串作为数据
- 使用 API Secret 作为密钥
- 计算 HMAC-SHA256 后与返回的签名比对
```

### 场景 2：Webhook 验证

GitHub、Stripe 等平台在发送 Webhook 时会附带 HMAC 签名，用此工具验证 Webhook 请求的真实性。

### 场景 3：数据完整性校验

在数据传输过程中，发送方计算 HMAC 并附带传输，接收方使用相同密钥重新计算并比对，确保数据未被篡改。

### 场景 4：JWT 签名调试

HS256 算法的 JWT 使用 HMAC-SHA256 进行签名，可用此工具手动验证 JWT 签名的正确性。

## 安全注意事项

> ⚠️ **重要提醒**

- 本工具**仅供开发测试使用**，请勿在生产环境中处理真实密钥
- 密钥应具有足够的随机性和长度（建议至少 32 字节）
- HMAC 的安全性依赖于密钥的保密性，切勿泄露密钥

## 算法对比

| 算法 | 输出长度 | 安全性 | 适用场景 |
|------|----------|--------|----------|
| **HMAC-SHA256** | 256 bit (64 hex) | 高 | API 签名、JWT HS256、通用验证 |
| **HMAC-SHA512** | 512 bit (128 hex) | 极高 | 高安全要求场景、密钥派生 |

## 快捷键与技巧

- 点击结果文本区域可直接复制到剪贴板
- 修改数据或密钥后重新点击「计算」即可更新结果
- 两种算法同时计算，方便对比选择

## 小结

HMAC 计算工具提供了简洁直观的界面，同时支持 HMAC-SHA256 和 HMAC-SHA512 两种算法。无论是调试 API 签名、验证 Webhook 还是校验数据完整性，都能快速得到结果。
