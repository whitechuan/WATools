# 对称加密工具使用指南

> 对称加密是信息安全的基础，使用相同的密钥进行加密和解密。本文介绍 WATools 中对称加密工具的功能和使用方法，支持 AES-256-GCM 和 ChaCha20-Poly1305 两种现代加密算法。

## 界面总览

对称加密工具采用**双栏布局**，左栏为加密区域、右栏为解密区域，顶部有实时状态栏。

## 核心功能

### 1. 加密（明文 → 密文 + Nonce）

将明文通过选定算法和密码加密为密文。

**使用步骤：**
1. 选择加密算法（AES-256-GCM 或 ChaCha20-Poly1305）
2. 在文本框输入要加密的明文
3. 在密码框输入加密密码
4. 点击「🔐 加密」按钮
5. 下方显示 Base64 编码的**密文**和**Nonce**

**示例：**
```
算法: AES-256-GCM
明文: Hello, World! 这是一条测试消息。
密码: my-secret-password

结果:
  密文: U2FsdGVkX1+QJ7R...（Base64 编码）
  Nonce: dG9vbHMtbm9uY2U=（Base64 编码）
```

### 2. 解密（密文 + Nonce → 明文）

将密文通过相同算法和密码还原为明文。

**使用步骤：**
1. 选择与加密时相同的算法
2. 在密文框粘贴 Base64 编码的密文
3. 在 Nonce 框粘贴 Base64 编码的 Nonce
4. 在密码框输入解密密码（必须与加密时相同）
5. 点击「🔓 解密」按钮
6. 下方显示解密后的明文

**示例：**
```
算法: AES-256-GCM
密文: U2FsdGVkX1+QJ7R...
Nonce: dG9vbHMtbm9uY2U=
密码: my-secret-password

结果:
  明文: Hello, World! 这是一条测试消息。
```

### 3. 状态栏

顶部状态栏实时显示操作状态：

- **空闲状态**：🔒 对称加密工具 — 仅供开发测试使用
- **成功状态**：✓ 操作完成 │ 算法: AES-256-GCM
- **错误状态**：⚠ 显示具体错误信息（如密码错误、密文格式无效等）

## 算法说明

### AES-256-GCM

| 特性 | 说明 |
|------|------|
| **全称** | Advanced Encryption Standard - 256-bit Galois/Counter Mode |
| **密钥长度** | 256 bit |
| **Nonce 长度** | 96 bit (12 bytes) |
| **认证标签** | 128 bit |
| **特点** | 硬件加速支持广泛，性能优秀 |

### ChaCha20-Poly1305

| 特性 | 说明 |
|------|------|
| **全称** | ChaCha20 流密码 + Poly1305 认证标签 |
| **密钥长度** | 256 bit |
| **Nonce 长度** | 96 bit (12 bytes) |
| **认证标签** | 128 bit |
| **特点** | 纯软件实现性能优秀，移动设备友好 |

### 如何选择？

- **通用场景**：优先选择 AES-256-GCM（硬件加速支持广泛）
- **移动/嵌入式**：优先选择 ChaCha20-Poly1305（无需 AES 硬件指令）
- 两者安全性相当，都是经过充分验证的现代加密方案

## 密钥派生说明

本工具将用户输入的**密码**通过 SHA-256 哈希运算派生为 256-bit 密钥：

```
实际密钥 = SHA-256(用户密码)
```

> 注意：这是简化的密钥派生方式，适用于开发测试。生产环境应使用 PBKDF2、Argon2 等专业密钥派生函数。

## Nonce 说明

- **Nonce**（Number used Once）是一次性随机数，每次加密时自动生成
- Nonce 与密文一起使用，解密时必须提供加密时生成的 Nonce
- **切勿重复使用相同密钥+Nonce 组合**，否则会严重损害安全性
- Nonce 本身不需要保密，可以与密文一起存储或传输

## 实际使用场景

### 场景 1：本地配置加密

将数据库连接字符串、API 密钥等敏感配置加密后存储在配置文件中，部署时解密使用。

### 场景 2：敏感数据传输测试

开发阶段测试端到端加密功能，验证加密和解密流程是否正确。

### 场景 3：数据备份加密

在备份敏感数据前进行加密，确保备份文件即使泄露也无法被直接读取。

## 安全注意事项

> ⚠️ **重要提醒**

- 本工具**仅供开发测试使用**，请勿用于生产环境的密钥管理
- 密码应具有足够的复杂度和长度（建议 16 位以上）
- **绝不要重复使用相同的 Nonce**（本工具每次加密自动随机生成）
- 妥善保管密文和 Nonce，两者都是解密所必需的
- 生产环境应使用专业的密钥管理系统（KMS）

## 快捷键与技巧

- 加密结果中的密文和 Nonce 都有独立的复制按钮
- 加密和解密使用独立的算法选择，方便测试跨算法兼容性
- 左右栏独立清空，互不影响

## 小结

对称加密工具提供了 AES-256-GCM 和 ChaCha20-Poly1305 两种现代加密算法的可视化操作界面。左栏加密、右栏解密的布局让加解密流程一目了然，适合开发测试中快速验证加密功能。
