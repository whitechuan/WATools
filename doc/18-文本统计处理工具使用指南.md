## 核心功能

### 1. 实时统计

输入文本后，右侧统计卡片会自动更新（300ms 防抖），显示以下指标：

| 指标 | 说明 |
|------|------|
| **字符数** | 文本总字符数（包含空格） |
| **不含空格** | 去除空格后的字符数 |
| **单词数** | 以空格分隔的单词数量 |
| **行数** | 文本总行数 |
| **段落数** | 以空行分隔的段落数量 |
| **字节数** | 文本的 UTF-8 字节大小 |

### 2. 文本处理

下半部分提供 7 种文本处理操作：

#### 🔠 转大写

将所有字符转换为大写。

```
输入: Hello World
输出: HELLO WORLD
```

#### 🔡 转小写

将所有字符转换为小写。

```
输入: Hello World
输出: hello world
```

#### 🅰️ 首字母大写

将每个单词的首字母转换为大写。

```
输入: hello world
输出: Hello World
```

#### 🧹 去重行

删除重复的行，保留第一次出现的顺序。

```
输入:                输出:
Apple                Apple
Banana               Banana
Apple                Cherry
Cherry
Banana
```

#### 🔢 排序行

按字母顺序对行进行排序。

```
输入:                输出:
Cherry               Apple
Apple                Banana
Banana               Cherry
```

#### ✂️ 去空行

删除所有空行。

```
输入:                输出:
Line 1               Line 1
                     Line 2
Line 2
                     
Line 3               Line 3
```

#### 📐 去首尾空白

去除每行开头和结尾的空白字符。

```
输入:                输出:
  Hello  World       Hello  World
    Test  Text       Test  Text
```

### 3. 处理结果操作

处理结果区域提供两个操作按钮：

- **📋 复制**：将处理结果复制到剪贴板
- **⬆️ 应用到输入**：将处理结果覆盖到输入框，方便继续处理

### 4. 状态栏

顶部状态栏会实时显示操作状态：

- **空闲状态**：📊 输入文本后自动统计
- **成功状态**：显示处理完成信息
- **错误状态**：⚠ 显示错误提示

## 实际使用场景

### 场景 1：代码字数统计

统计文章或代码的字符数、单词数，用于评估文档规模或计算翻译费用。

### 场景 2：数据清洗

从日志或数据库导出的文本中去除重复行、空行，整理出干净的数据列表。

### 场景 3：格式化文本

批量转换大小写，统一文本格式，如将配置文件中的键名统一为小写。

### 场景 4：排序整理

对列表数据进行排序，如整理依赖包列表、功能清单等。

### 场景 5：去空白处理

清理从 PDF 或其他来源复制的文本中多余的首尾空白。

## 统计指标详解

### 字符数 vs 字节数

- **字符数**：文本中字符的个数（包括空格）
- **字节数**：UTF-8 编码下文本占用的字节数

对于纯 ASCII 文本，两者相等；对于包含中文或其他多字节字符的文本，字节数会大于字符数。

```
文本: Hello
字符数: 5
字节数: 5

文本: 你好
字符数: 2
字节数: 6  (每个中文字符在 UTF-8 中占 3 字节)
```

### 单词数计算规则

单词数按空格分隔计算，连续空格算作一个分隔符。

```
文本: Hello   World  Test
单词数: 3
```
